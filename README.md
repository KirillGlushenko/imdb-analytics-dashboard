
# IMDb Analytics Dashboard

Интерактивный аналитический дашборд для исследования отзывов IMDb, разработанный на Python и Streamlit.

## Возможности

- Анализ 49 578 отзывов IMDb.
- Отображение основных показателей (KPI).
- Распределение положительных и отрицательных отзывов.
- Интерактивные графики Plotly.
- Анализ длины отзывов.
- Поиск отзывов по словам и фразам.
- Фильтрация по тональности.
- Анализ 15 наиболее популярных слов.
- Сравнение лексики положительных и отрицательных отзывов.
- Экспорт отфильтрованных данных в CSV.
- Автоматическое формирование аналитических выводов.

## Используемые технологии

- Python
- Pandas
- Streamlit
- Plotly

## Источник данных

Для анализа используется датасет IMDb с Kaggle:

[IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

Датасет содержит тексты отзывов и готовые метки тональности `positive` и `negative`.

Перед использованием данные очищаются от HTML-тегов, лишних пробелов и дубликатов.

## Установка и запуск

1. Склонировать репозиторий.
2. Установить Python 3.10 или новее.
3. Создать виртуальное окружение:

```powershell
py -m venv .venv
```

4. Активировать окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

5. Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

6. Подготовить файл `imdb_clean.csv` с колонками `review`, `sentiment`, `review_length` и поместить его рядом с `app.py`.

Для получения очищенного файла можно воспользоваться скриптом подготовки данных из первого проекта:

[IMDb Sentiment Monitoring](https://github.com/KirillGlushenko/imdb-sentiment-monitoring)

7. Запустить приложение:

```powershell
python -m streamlit run app.py
```

После запуска дашборд откроется в браузере.

## Основные выводы

Положительные и отрицательные отзывы представлены практически поровну.

В положительных отзывах чаще встречаются слова `great`, `excellent` и `amazing`, а в отрицательных — `bad`, `worst`, `boring` и `terrible`.

Поиск, фильтры и интерактивные графики позволяют изучать распределение тональности и особенности текстов.

## Ограничения

- Используются готовые метки тональности из исходного датасета.
- Модель машинного обучения не обучается.
- Датасет не содержит дат публикации отзывов.
- Дашборд анализирует статический набор данных, а не поток отзывов в реальном времени.
